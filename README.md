# 城主村莊 - City Builder（重製版）

離線放置型城市經營遊戲。玩家管理四個採集點（森林、海灘、礦山、平原），
建設採集/加工建築，離線也持續生產資源。

## 專案結構

```
city_builder/
├── index.html              # 主頁面
├── css/
│   └── style.css
├── data/
│   ├── resources.js         # 所有資源定義
│   ├── gatheringSpots.js     # 採集點與等級表
│   ├── buildings.js          # 各採集點可蓋的建築
│   └── recipes.js            # 加工鏈配方
├── js/
│   ├── core/                 # 遊戲狀態、存讀檔、主迴圈（開發中）
│   ├── systems/               # 採集/加工/升級邏輯（開發中）
│   └── ui/                    # 畫面渲染與互動（開發中）
└── README.md
```
