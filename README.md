# 城主村莊 - City Builder（重製版）

離線放置型城市經營遊戲。玩家管理四個採集點（森林、海灘、礦山、平原），
建設採集/加工建築，離線也持續生產資源。介面採分頁式設計：人物資訊、生產、加工、建築。

## 核心機制

- **自動生產**：已建成的採集建築每 10 秒結算一次產出，離線也會照算（上限 8 小時）
- **徒手採集**：每次消耗 1 點體力、冷卻 3 秒，依採集點目前等級查機率表隨機獲得物品，
  同時獲得經驗值
- **人物等級**（跟採集點等級分開）：經驗值累積升級，等級越高，進階物品的採集機率加成越高
- **體力系統**：基礎上限 20，每 5 秒自動恢復 1 點，也可以吃食物（生食或加工食品）立即恢復
- **五格存檔**：每格獨立進度，可個別存檔/讀取/清空（清空前會要求確認）
- **分頁介面**：
  - 🧑 人物資訊：等級/經驗值/體力狀態、進食、存檔管理
  - 🌾 生產：採集點狀態、自動生產進度條、徒手採集、機率表
  - ⚒️ 加工：已建成加工建築的配方、加工佇列
  - 🏗️ 建築：尚未建造的建築（含成本）、採集點升級

## 如何本機測試

用瀏覽器打開 `index.html` 即可，建議搭配簡易 local server（例如 `npx serve .`）
以避免部分瀏覽器對本機檔案 localStorage 的限制。
