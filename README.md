# 城主村莊 - City Builder（重製版）

離線放置型城市經營遊戲。玩家管理四個採集點（森林、海灘、礦山、平原），
建設採集/加工建築，離線也持續生產資源。介面採分頁式設計：倉庫、生產、加工、建築，
人物資訊（等級/經驗值/體力/金幣）常駐在頁面最上方。

## 核心機制

- **建築等級 vs 採集點等級（完全分開）**：
  - 建築等級：每個建築獨立升級，直接整數倍增加每輪產出（不會有 1.3 個這種情況）
  - 採集點等級：只負責解鎖新建築、決定徒手採集的機率表
- **自動生產**：已建成的採集建築每 10 秒結算一次，離線也會照算（上限 8 小時）
- **徒手採集**：消耗 1 點體力、冷卻 3 秒，依採集點等級查機率表隨機獲得物品，同時獲得經驗值
- **人物等級**：經驗值累積升級，等級越高，機率表裡的進階物品權重加成越高
- **體力系統**：基礎上限 20，每 5 秒自動恢復 1 點，也可以吃食物（生食或烹飪料理）立即恢復
- **烹飪系統**：平原的「廚房」建築可以把食材煮成料理（烤肉、烤魚、蔬菜燉湯、麵包、海鮮湯），
  恢復體力比生食高很多
- **平原分類**：種植（農田/灌溉/穀倉/磨坊）、畜牧（雞舍/裁縫坊）、烹飪（廚房）、商店（市集）
  四個子系統，畫面上會分組顯示
- **商店**：平原建造「市集」後解鎖，可以賣出任何資源換金幣，也能用金幣買回少數基礎建材應急
- **五格存檔**：每格獨立進度，可個別存檔/讀取/清空（清空前會要求確認）

## 分頁介面

- 🏠 倉庫：資源清單、進食、商店、存檔管理
- 🌾 生產：採集點狀態、自動生產進度條、徒手採集、機率表
- ⚒️ 加工：已建成加工建築的配方（含烹飪）、加工佇列
- 🏗️ 建築：採集點升級（卡片最上方）、建造新建築、建築個別升級

## 如何本機測試

用瀏覽器打開 `index.html` 即可，建議搭配簡易 local server（例如 `npx serve .`）
以避免部分瀏覽器對本機檔案 localStorage 的限制。
